# مهامنا — الصف الثالث الثانوي
موقع عربي RTL مناسب للجوال وGitHub Pages. مصدر البيانات Google Sheets، ويُقرأ كل 60 ثانية.

## محتويات مجلد الموقع
- index.html — الصفحة الرئيسية
- style.css — التصميم
- app.js — عرض المهام والفلترة والتحديث
- config.js — رابط Google Apps Script ورابط الجدول
- Code.gs — انسخه فقط إلى Apps Script **ولا يلزم رفعه ضمن المستودع العام**

## إعداد ملف البيانات
ارفع `قالب_مهام_ثالث_ثانوي.xlsx` إلى Google Drive، افتحه بـ Google Sheets واحفظه كجدول Google Sheets أصلي.
اسم التبويبات: `المهام` و`المواد` و`أنواع المهام`.
في تبويب المهام أعمدة: id,title,subject,type,notes,link,start,end,created,active.
املأ الأوقات كـ **نص** بالشكل `2026-11-03T23:00` (وقت الرياض). عند التعديل أو الحذف من الجدول نفسه سيظهر التغيير في الموقع بعد التحديث. لا تغيّر أسماء التبويبات أو رؤوس الأعمدة أو ترتيبها.
يمكن وضع `لا` في عمود active لإخفاء المهمة دون حذفها.

## الربط
1. افتح Google Sheets > الإضافات (Extensions) > Apps Script.
2. استبدل محتوى Code.gs بالنص من ملف `Code.gs` ثم احفظ.
3. نشر (Deploy) > عملية نشر جديدة (New deployment) > تطبيق ويب (Web app).
4. التنفيذ باسم: **أنا** (Me). من يمكنه الوصول: **أي شخص** (Anyone). وافق على الأذونات.
5. انسخ رابط تطبيق الويب النهائي المنتهي بـ `/exec`.
6. افتح `config.js` واستبدل `apiUrl: ""` بالرابط. وأضف رابط الجدول إلى `sheetUrl` لعرض زر الإدارة.
7. اضبط صلاحيات ملف Google Sheets: مشاركة القراءة العامة **غير مطلوبة**؛ مشاركة التعديل فقط مع الطالب المسؤول. *مهم*: API يعرض المهام لعامة زوار الموقع لذلك لا تضع معلومات خاصة في الجدول.
8. عندما تعدل كود Apps Script لاحقًا، اختر Deploy > Manage deployments > Edit > New version > Deploy.

## GitHub Pages
1. افتح https://github.com/new وأنشئ مستودعًا عامًا مثل `class-tasks`.
2. ارفع `index.html`, `style.css`, `app.js`, `config.js` (في جذر المستودع).
3. Settings > Pages > Build and deployment > Deploy from a branch > `main` > `/(root)` > Save.
4. رابطك سيكون: `https://YOUR-USERNAME.github.io/class-tasks/`.
5. إذا ظهر 404 تحقق من وجود `index.html` مباشرةً في جذر المستودع ومن كتابة اسم المستودع في الرابط تمامًا.

## ملاحظات
- تظهر 3 مهام توضيحية تلقائيًا **فقط** قبل إضافة API؛ لا تعتبر المهام بيانات حقيقية.
- حالة المهمة تُحسب من تاريخ البداية والنهاية، ولا يوجد حساب مستخدم أو تنبيهات دفع.
- ملف الجدول هو لوحة الإدارة الآمنة بصلاحيات Google؛ واجهة الموقع للعرض فقط.
- تعطيل المهام أو حذفها أو تعديلها متاح مباشرة من Google Sheets.
- إذا كان عرض الوقت خاطئًا، اضبط منطقة جدول البيانات الزمنية على Asia/Riyadh، وأدخل التاريخ كنص وفق الصيغة الموضحة.
